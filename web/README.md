# Interfaz de Cauce

Svelte + TypeScript + Vite. Consulta el README de la raíz para la configuración completa y el arranque del servidor Python.

```powershell
npm.cmd ci
npm.cmd run dev
```

La interfaz se sirve en http://127.0.0.1:5173. Las peticiones `/api` se envían al servidor Python en http://127.0.0.1:8000.

```powershell
npm.cmd run check
npm.cmd run build
```
